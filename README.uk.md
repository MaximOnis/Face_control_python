# Face Control

Програма для розпізнавання облич за допомогою вебкамери та контролю доступу користувачів.

## Технології

- Python

- OpenCV

- face_recognition

- CustomTkinter

- Pillow

## Запуск

Встановити залежності:


```bash
pip install -r requirements.txt
```

Додати фотографії зареєстрованих користувачів до папки owners/.

## Запустити програму:

python main.py
