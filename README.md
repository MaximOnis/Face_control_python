# Face Control

A program for facial recognition using a webcam and user access control.

## Technologies

- Python

- OpenCV

- face_recognition

- CustomTkinter

- Pillow

## Getting Started

Install dependencies:


```bash
pip install -r requirements.txt
```

Add photos of registered users to the owners/ folder.

## Run the program:

python main.py
